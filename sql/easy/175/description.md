## 175. Объединение двух таблиц

### Таблица: Person

| Имя столбца | Тип     |
|-------------|---------|
| personId    | int     |
| lastName    | varchar |
| firstName   | varchar |

`personId` — это первичный ключ (уникальное значение) для этой таблицы.  
В таблице содержится информация о людях: идентификатор, фамилия и имя.

### Таблица: Address

| Имя столбца | Тип     |
|-------------|---------|
| addressId   | int     |
| personId    | int     |
| city        | varchar |
| state       | varchar |

`addressId` — это первичный ключ (столбец с уникальными значениями) для этой таблицы.  
Каждая строка этой таблицы содержит информацию о городе и штате одного человека с идентификатором `personId`.

Напишите решение, которое выведет имя, фамилию, город и штат каждого человека в таблице `Person`. Если адрес для
`personId` отсутствует в таблице `Address`, выведите `null` вместо города и штата.

Верните таблицу результатов в любом порядке.

Формат результатов показан в следующем примере.

---

**Пример 1:**

**Ввод:**

Таблица `Person`:

| personId | lastName | firstName |
|----------|----------|-----------|
| 1        | Wang     | Allen     |
| 2        | Alice    | Bob       |

Таблица `Address`:

| addressId | personId | city     | state      |
|-----------|----------|----------|------------|
| 1         | 2        | New York | New York   |
| 2         | 3        | Leetcode | California |

**Вывод:**

| firstName | lastName | city     | state    |
|-----------|----------|----------|----------|
| Allen     | Wang     | null     | null     |
| Bob       | Alice    | New York | New York |

**Пояснение:**

В таблице `Address` нет записи для `personId = 1`, поэтому для этого человека значения `city` и `state` равны `null`.  
Запись с `addressId = 1` содержит адрес для `personId = 2`.
